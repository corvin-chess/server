Rust Axum server for Corvin. Current surface: `GET /health` returns HTTP 200 with plain body `ok` plus a trailing newline for Compose probes. Planned surfaces: WebSocket play protocol, lobby and matchmaking, clocks, ratings, tournaments, and HTTP API. Intended dependencies: PostgreSQL for durable data, Redis for live games and presence, [chess-core](https://github.com/corvin-chess/chess-core) for legality, and optional analysis via [engine](https://github.com/corvin-chess/engine). Fair-play review hooks are planned to consume the public [fairplay](https://github.com/corvin-chess/fairplay) library; private thresholds stay out of this repository.

```bash
git clone https://github.com/corvin-chess/server.git
cd server
cargo run
```

Defaults: listen on `0.0.0.0:3000` (container-friendly). For local-only bind, set `HOST=127.0.0.1`. Override port with `PORT`. Check liveness with `curl -sf http://127.0.0.1:3000/health`.

Binary crate `corvin-server`: `src/lib.rs` owns the Axum router; `src/main.rs` binds `HOST`/`PORT` and serves with graceful shutdown. Planned modules: `src/ws`, `src/api`, `src/match`, `src/clock`, `src/rating`, `migrations`. Server is authoritative for game state and clocks; clients reconcile to protocol events. See organization ADRs and [website](https://github.com/corvin-chess/website) once docs are published.
