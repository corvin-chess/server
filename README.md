<p align="center"><img src="https://readme-typing-svg.demolab.com?font=IBM+Plex+Mono&weight=700&size=18&color=8FA3D9&center=true&vCenter=true&width=420&height=40&duration=1&pause=1000000&letterSpacing=6px&lines=OVERVIEW" alt="Overview" /></p>

Planned Rust Axum server for Corvin. Intended surfaces: WebSocket play protocol, lobby and matchmaking, clocks, ratings, tournaments, and HTTP API. Intended dependencies: PostgreSQL for durable data, Redis for live games and presence, [chess-core](https://github.com/corvin-chess/chess-core) for legality, and optional analysis via [engine](https://github.com/corvin-chess/engine). Fair-play review hooks are planned to consume the public [fairplay](https://github.com/corvin-chess/fairplay) library; private thresholds stay out of this repository. No application source is in this repository yet.
